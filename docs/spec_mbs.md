# パススルー MBS の仕様（P11-5）

実装は `crates/riemann/src/mbs.rs`、R の入口は `crates/riemann-r/R/mbs.R`、比較文書は `comparison/chapters/ch11_hull_white.qmd` の「Mortgage-backed securities」節である。QuantLib には対応する機能がないので、比較の基準はすべて LagrangeFinance II-8.8 である。

## 1. LagrangeFinance II-8.8 の条件【ソース確認】

- **商品**：元本と利息がそのまま投資家に支払われる簡略なパススルー。デフォルトと損失は含めない。
- **予定元本**：当初の約定金利と期間で決めた月額返済額を固定し、期限前返済の後も再計算しない。予定元本は「返済額 − 利息」で、残高を上限とし、最終月は残高のすべて。
- **期限前返済**：PSA の基準 `CPR_PSA = min(0.002 m, 0.06)` に、借換えの誘因を掛けた教材用の規則 `CPR = min(0.60, α CPR_PSA exp(β (c − f_m − k)))`。`SMM = 1 − (1 − CPR)^(1/12)`、期限前返済額は `(期初残高 − 予定元本) × SMM`。
- **投資家の利息**：期初残高 × パススルー金利 / 12。
- **金利モデル**：Hull–White の月次の短期金利。状態を厳密に 1 か月ずつ進め、短期金利 = 状態 + `flat + σ²/(2a²)(1 − e^{−at})²`。R の乱数で 20 経路（対称変量）。借換え金利は `max(0, 短期金利 + 3%)` とする代理変数。
- **割引**：月 m を `exp(−Σ_{i≤m} r_i / 12)` で割り引く（月末の短期金利の和による近似）。
- **OAS**：`P(z) = E[Σ CF_m exp(−∫(r + z))]`。経路ごとの現在価値の平均を価格とし、市場価格に一致する z を解く。LagrangeFinance では、数値例は金利 4% 固定の静的 OAS（`uniroot`）だけで、Hull–White 経路の OAS は定義のみである。

**期限前返済は最適行使ではない。** 借り手の行動を、経過月数と借換えの誘因の関数として外から与える規則であり、Longstaff–Schwartz のように継続価値を回帰して行使を最適化することはしない。

## 2. Riemann の実装

| 関数（R） | 内容 |
|---|---|
| `create_mbs_pass_through` | プールの条件を作り、一度だけ検証する |
| `compute_mbs_cashflows` | 借換え金利の月次の列から、月次のキャッシュフローを計算する |
| `compute_mbs_path_values` | 経路 × 月の短期金利と借換え金利の行列から、経路ごとの価格と WAL を計算する |
| `compute_mbs_oas` | 経路の平均価格が市場価格に一致するスプレッドを解く（1 本の一定の経路なら静的 OAS） |
| `generate_hull_white_monthly_rates` | LagrangeFinance と同じ式の月次 Hull–White 短期金利を、このライブラリの乱数で作る |

**設計**（`docs/design_distributed.md` 4 章）：条件と行列の形は入口で一度だけ検査し、計算の中では検査しない。短期金利と借換え金利は、経路 × 月の連続した配列として受け取る。借換え金利を短期金利から作る規則（`max(0, r + 3%)` など）は R 側で決め、計算コアには持ち込まない。

**LagrangeFinance との違い**：

| 項目 | LagrangeFinance | Riemann |
|---|---|---|
| 返済額 | 当初の返済額を固定 | 既定は同じ（`amortization = "fixed_payment"`）。標準的な再計算（`"reamortized"`）も選べる |
| 借換え金利 | 関数の中で `max(0, r + 3%)` を作る | 行列として受け取る |
| OAS の解法 | `uniroot` の既定の精度（約 1.2e-4） | Brent 法、精度 1e-12 |
| Hull–White の乱数 | R の `rnorm`（seed 48） | このライブラリのカウンター型乱数 |

## 3. 照合結果【実行照合済み】（2026-11-04）

| 対象 | 件数 | 結果 |
|---|---|---|
| シナリオ別の WAL、固定 4% の価格、経路金利の価格、元本合計 | 12 | PASS、差は最大 1.1e-13 |
| LagrangeFinance の 20 経路（同じ金利行列）の価格と WAL | 40 | PASS、差は最大 1.7e-13 |
| 20 経路の平均価格（117.4939） | 1 | PASS |
| 静的 OAS（PSA 0・50・100%、価格 95・105） | 6 | N/C、差は最大 0.26 bp |
| このライブラリの乱数による 2 万経路の平均価格 | 1 | N/C（117.3165、乱数と経路数が違う） |

**静的 OAS の差の原因**：LagrangeFinance は `uniroot` を既定の精度で使う。LagrangeFinance の OAS で価格を計算し直すと、想定価格 105 の場合に最大 0.033 下回った（104.9666）。Riemann の OAS では差は 1e-9 以下である。比較元の解法の精度による差であり、Riemann の不具合ではない。

## 4. 未対応

- CMO のトランシェ配分（Sequential、PAC、TAC）、バーンアウト、季節性、反応の遅れ、延滞・デフォルト、手数料、支払遅延。
- 借換え金利を長期金利や貸出スプレッドから作るモデル。期限前返済関数の過去データへの当てはめ。
- 短期金利の期間積分による割引（II-8.4 と同じ扱い）。
- 日本の PSJ。
