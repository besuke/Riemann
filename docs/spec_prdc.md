# PRDC の仕様（P10）

実装は `crates/riemann/src/prdc.rs`、R の入口は `crates/riemann-r/R/prdc.R` である。定義は GaussQuant の `prdc_coupon_GQL` と LagrangeFinance II-9、III-7 に従う。

## 1. 対象とモデル

クーポンは `clamp(leverage × S / fx_base - subtraction, floor, cap)` で、最後のクーポン日に償還額を支払う。一部のクーポン日には固定レートを指定できる。

**モデルは LagrangeFinance III-7 と同じ簡略版である。**

- FX はクーポン日の間で対数正規で、ボラティリティは一つの定数である。
- 国内と外国の金利カーブは確定的である。
- 乱数の源は一つである。**確率的な金利（3 因子のモデル）は含まない。** 感応度が多数になるのは、両方のカーブのノードについて微分するからである。
- コール、ターゲット償還、ノックアウトは含まない。

したがって、最終目標として書いた「PRDC の多因子 MC」のうち、LagrangeFinance III-7 が扱う範囲を実装した段階である。確率的な金利（3 因子）は 5 章で追加した（2026-11-07）。

## 2. 計算

| 方法 | 入力 | 内容 |
|---|---|---|
| 解析解 | `paths = 0` | 各クーポンを、フロアと FX のコール・スプレッドの和に分解する |
| モンテカルロ | `paths > 0` | クーポン日ごとの FX パス。カウンター方式の乱数、対称変数 |

**torch の置き換え**：どちらも自動微分で、FX スポット、ボラティリティ、両方のカーブのノードについて 1 回の計算で微分する。MC の感応度はパスごとの微分である。フロアとキャップの折れ目では、それぞれの側の傾きを使う。クーポンは FX について連続なので、この扱いでよい。デジタルやバリアなど不連続なものには、そのままでは使えない。

**2 階微分**：`autodiff` で求められるが、この段階では公開していない。

## 3. 照合結果【実行照合済み】（2026-11-01）

入力はすべて合成である。市場価格との照合はしていない。これらはモデルの値である。

| 確かめた内容 | 方法 | 結果 |
|---|---|---|
| MC と解析解 | 40 万パス（対称変数） | 差は標準誤差の 5 倍以内（Rust のテスト、検証 QMD） |
| FX のデルタ・ベガ、カーブのノード | MC の AD と解析解の AD | 2〜3% 以内（Rust のテスト） |
| 解析解の AD | 数値差分、カーブの作り直し | 相対 1e-4 以内 |
| MC の AD | 同じ乱数での数値差分 | 相対 1e-3 以内 |
| スレッド数 | 1 と 4 | 完全に一致 |
| GaussQuant `prdc_npv_GQL` | 同じ気配から各自でカーブを作り、MC（10 万パス）と解析解を比べる | 基準内（検証 QMD） |

GaussQuant は QuantLib の乱数を使うので、パスごとには比べられない。LagrangeFinance III-7 の `torch` の値は、精度の指定がなく、乱数も違うので、基準値にしていない。

## 4. 未対応

- 3 因子モデル（5 章）の感応度（自動微分）、金利のボラティリティの校正、FX ボラティリティの期間構造。
- コール、ターゲット償還、ノックアウト。
- FX ボラティリティの期間構造とスマイル。
- 平滑化と尤度比法（不連続なペイオフの感応度）。

## 5. 3 因子モデル（2026-11-07）【閉じた式、無裁定の関係、R で書いた別実装の Euler 法で確認】

`compute_prdc_three_factor_analytic`、`compute_prdc_three_factor_monte_carlo`、`generate_prdc_three_factor_paths`（R は `compute_prdc_three_factor_value`）。`docs/spec_rates_fx_extension.md` 4 章の案 1〜4 による。

**モデル**（国内のリスク中立測度）：

- 国内と外国の短期金利は Hull-White：`r = x + φ(t)`、`dx = -a x dt + σ dW`、`φ` は各カーブに合わせる。外国金利には国内測度へのクオント調整のドリフト `-ρ_fX σ_f σ_X` が付く。
- FX は対数正規：`dS / S = (r_d - r_f) dt + σ_X dW_X`。三つのブラウン運動の相関は `ρ_df`、`ρ_dX`、`ρ_fX`。

**閉じた式**：クーポンは自分の日付の FX にしか依存しない。日付 `T` の国内フォワード測度では、FX フォワード `F(t, T) = S P_f(t, T) / P_d(t, T)` はマルチンゲールで、拡散項は `σ_X dW_X - σ_f B_f(t, T) dW_f + σ_d B_d(t, T) dW_d`（`B(τ) = (1 - e^{-aτ}) / a`）。したがって `ln F(T, T)` は正規で、分散は

`V(T) = ∫_0^T [σ_X² + σ_f² B_f² + σ_d² B_d² - 2 ρ_fX σ_X σ_f B_f + 2 ρ_dX σ_X σ_d B_d - 2 ρ_df σ_d σ_f B_d B_f] dt`

（Simpson 則、2000 区間）。各クーポンは、1 章の解析解のコール・スプレッドに、ボラティリティ `sqrt(V(T) / T)` を入れたものになる。近似ではない。

**モンテカルロ**：`(x_d, x_f, W_X)` を、最大 `1 / steps_per_year` 年の刻みで、OU 過程の厳密な推移（条件付き共分散の Cholesky 分解、`x_f` はクオント調整のドリフト込み）で進め、`I = ∫x` は台形則。カーブに合わせた `φ` から、`exp(-∫r_d) = P_d(0, T) exp(-I_d - V_d / 2)`、`ln S(T) = ln S + ln(P_f / P_d) + I_d - I_f + (V_d - V_f) / 2 - σ_X² T / 2 + σ_X W_X(T)`（`V = Var(I)`。外国の `V_f` は外国測度での分散）。離散化誤差は台形則の分だけ。

**検査**（Rust と R のテスト）：

- 金利のボラティリティが 0 なら、`V(T) = σ_X² T`（1e-15）で、1 章の解析解と相対 1e-14 以内（R では 1e-13）で一致する。
- 金利のボラティリティ 1%、1.2%、相関 `(0.3, -0.2, 0.4)`、20000 パス、年 12 ステップで、各クーポン日の `E[D_d] = P_d(0, T)`、`E[D_d S] = S P_f(0, T)`（クオント調整の確認）、`E[D_d S²] / (P_d F²) = exp(V(T))`（分散の式の確認）が、標準誤差の 4 倍以内で成り立つ。ノートのモンテカルロは閉じた式と標準誤差の 4 倍以内で一致し、閉じた式は 1 章の簡略モデルと 0.1% 以上違う。
- 4 章の案 4：R で別に書いた Euler 法（`r_d`、`r_f`、`ln S` を 0.01 年刻み、R の乱数、平坦なカーブで `φ(t) = r + σ²/(2a²)(1 - e^{-at})²`）の値が、閉じた式と標準誤差の 4 倍 + 2e-4 以内で一致する（R のテスト）。
- 相関行列にならない相関、負のボラティリティ、減少するクーポン日はエラー。

**数値の例**（2026-11-07 の実行。平坦な連続複利カーブ、円 1.2%、ドル 3.5%、S = 150、σ_X = 11%、HW `(a, σ)` は国内 `(0.03, 1%)`、外国 `(0.05, 1.2%)`、相関 `(0.3, -0.2, 0.4)`、1 章のテストと同じ 5 年のクーポン、名目 1）：

| 方法 | 値 | 標準誤差 |
|---|---:|---:|
| 閉じた式（3 因子） | 1.047238 | |
| モンテカルロ 20000 パス | 1.047791 | 1.0e-3 |
| モンテカルロ 200000 パス | 1.046663 | 3.1e-4 |
| R の Euler 法 20000 パス | 1.047497 | 9.9e-4 |
| 1 章の簡略モデル（金利は確定的） | 1.050903 | |

各クーポンの実効ボラティリティは 1 年 0.10686、2 年 0.10422、3 年 0.10208、4 年 0.10043、5 年 0.09923（この相関では、FX と外国金利の正の相関が分散を減らす）。

**範囲**：コール、ターゲット償還、ノックアウトはない。3 因子モデルの感応度（自動微分）と、金利のボラティリティの校正はしていない。QuantLib v1.42 には 3 因子の FX・金利モデルがないので、外部の照合は文献の数値例が未着手。
