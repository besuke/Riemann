# 金利・通貨機能の拡張（2026-11-04 着手）

クロスカレンシーと LMM を含め、金利・通貨機能の範囲を広げる（2026-11-04 のユーザーの指示）。それまでの「クロスカレンシーは後回し」「LMM は Caplet と相関まで」の判断は、この指示で置き換わる。移植済みの部分は繰り返さず、不足する拡張を次の順で進める。

1. 通貨ベーシスの期間構造
2. 担保 CTD（Cheapest to Deposit）の本源的価値
3. FMM（後決め RFR の期間金利モデル）
4. LMM の共同経路と校正

検証は QuantLib、解析解、無裁定の関係で行い、細かな差の追究より機能の充実を優先する。担保 CTD の時間価値と PRDC の多因子モデルは、検証方法の案を 4 章に整理して後続課題に残す。段階ごとにコミットする。

## 4. 後続課題と検証方法の案【設計案】

**担保 CTD の時間価値**：将来の担保選択の期待値は、翌日物金利と通貨ベーシスの確率過程に依存する。解析解はない。

- 案 1：通貨ベーシスのスプレッドの差を正規過程とし、日ごとの選択を「スプレッドの差に対するフロア」の連続体と見る。各日のフロアは Bachelier の式で解析的に評価できる。モンテカルロの結果をこの式と比べる。
- 案 2：ボラティリティを 0 に近づけると本源的価値（段階 2）に収束すること、通貨が 1 つなら時間価値が 0 になることを無裁定の検査とする。
- 案 3：外部の比較先として、公開論文の数値例（Fujii–Shimada–Takahashi の担保選択の論文など）を再現できるか調べる。数値例と入力が十分に書かれているかは未確認。

**PRDC の多因子モデル**：国内金利・外国金利（Hull–White 2 本）と FX（対数正規）の 3 因子。

- 案 1：金利のボラティリティを 0 にすると、現在の確定的な金利のモデル（P10）に一致すること。
- 案 2：FX フォワードの期待値が `S × Pf / Pd` に一致すること（国内リスク中立測度での外国金利のクオント調整を含む無裁定の検査）。ゼロクーポン債の価格が初期カーブを再現すること。
- 案 3：FX のヨーロピアン・オプションには、3 因子のガウス型モデルで解析式がある（対数 FX の分散が金利の寄与を含む）。モンテカルロをこの式と比べる。
- 案 4：QuantLib には 3 因子の FX・金利モデルがない（v1.42）。外部の比較先は、文献の数値例か、別実装（R で小さく書いた Euler 法）との比較になる。

## 5. 段階 1：通貨ベーシスの期間構造（2026-11-04）【ソース確認・実行照合済み】

実装は `crates/riemann/src/xccy.rs`（ブートストラップの 1 回の走査は `crates/riemann/src/bootstrap.rs` に切り出し、債券のカーブと共有）、R の入口は `crates/riemann-r/R/xccy.R`。

**計算**（QuantLib v1.42 の `FxSwapRateHelper`、`ConstNotionalCrossCurrencyBasisSwapRateHelper`、`MtMCrossCurrencyBasisSwapRateHelper`、`PiecewiseLogLinearDiscount`）：

- 通貨の組は base/quote で、FX は base 1 単位あたりの quote 通貨の額。担保でない通貨の割引カーブを、割引係数の対数線形でブートストラップする。担保通貨は `collateral_curve` で割り引く。
- FX スワップ：`(担保の比 / 解く曲線の比 - 1) × スポット`（担保が base なら逆）。日付は評価日を営業日に直し、決済日数だけ進め、期間を足す。
- ベーシス・スワップ：両レグとも名目 1 で、開始と満期に名目を交換する。翌日物レグのクーポンは各指数のカーブで `P(開始) / P(終了) - 1`（同じカーブでの日次複利）。名目リセット型は、各期の開始に名目を FX フォワード（相手通貨の割引係数との比）に直し、期首に貸して期末に利息付きで受け取る。ベーシスはどちらのレグにも付けられる。
- 結合カレンダー：Riemann には QuantLib の `JointCalendar` がないので、`HolidayCalendar::joined_with` で一方の休日を期間内だけ他方に加える。R の既定は二つの指数のカレンダーの結合。

**照合**（QuantLib R パッケージ 1.42、`tools/golden/p12_xccy_curves.R`、`crates/riemann/tests/golden_xccy_curves.rs`）：USD/JPY（円担保、名目一定と base リセット、ドル担保で quote リセット）と EUR/USD（ドル担保、名目一定と base リセット）の 5 ケース、計 21 節点の割引係数が差 3.3e-16 以内で一致した。指数の予測カーブはフラットな連続複利で与えた。

**円ベーシス込み ASW の拡張**（`compute_yen_asset_swap_on_basis_curve`）：II-3.7.4 の一定の `z` の代わりに、ブートストラップした「円担保の外貨の割引カーブ」`Pb` から FX フォワード `S [Pb(t)/Pb(t0)] / [Pj(t)/Pj(t0)]` を作る。名目一定、担保の選択なしは従来と同じ。

**無裁定の検査**：外貨のカーブを一定の `z`（Actual/365 の連続複利）だけずらしたカーブを `Pb` として渡すと、従来の簡略化モデル（GaussQuant と照合済み）の円 ASW スプレッドと差 1e-13 以内で一致する（GaussQuant の 45 件すべてで確認、`golden_asset_swaps.rs`）。ブートストラップしたベーシス・カーブでは、ベーシスを 10bp 動かすと円 ASW スプレッドがほぼ 10bp 動く（R のテスト）。

**未対応**：固定対変動の通貨スワップ（`ConstNotionalCrossCurrencySwapRateHelper`）、支払いの遅延のあるベーシス・スワップ、評価日前の fixing、名目リセット型の ASW、気配についての感応度（カーブは与えたカーブとして扱う）。

## 6. 段階 2：担保 CTD の本源的価値（2026-11-04）【実行照合済み（構成と無裁定の検査）】

実装は `crates/riemann/src/ctd.rs`、R は `create_ctd_curve`（`crates/riemann-r/R/xccy.R`）。同じキャッシュフローの、担保通貨ごとの割引カーブ（円担保なら TONAR、ドル担保なら段階 1 の `bootstrap_xccy_curve` でドルを担保にした円のカーブ）を与え、暦日ごとのフォワード `f_c = ln(P_c(d) / P_c(d + 1))` の最大を選んで割引係数をつなぐ（`exp(-Σ max_c f_c)`）。結果は日ごとの節点の対数線形のカーブと、同じ担保が続く期間の表（優位幅つき）。今日のフォワードだけによる選択で、時間価値・ヘアカット・差替えの条件は含まない。

**検査**（Rust と R のテスト）：通貨が 1 つなら元のカーブと差 1e-13 以内で一致する。どの日付でも、どの単一通貨の割引係数より大きくならない。交差するカーブでは、短期と長期で選ぶ通貨が入れ替わる。外部の照合先はない。

## 7. 段階 3：FMM（後決め RFR の期間金利）（2026-11-05）【解析式とモンテカルロで確認】

実装は `crates/riemann/src/fmm.rs`、R は `compute_backward_forward_rate`、`compute_backward_caplet_value`（`crates/riemann-r/R/fmm.R`）。

**計算**（Lyashenko–Mercurio の generalized FMM）：

- 期間 `[T_s, T_e]` の後決め金利 `R` のフォワードは `(A(t) P(t, max(t, T_s)) / P(t, T_e) - 1) / τ`。`A(t)` は確定済みの fixing の複利係数（期間前は 1）。確定済み部分と未確定部分を一つの式でつなぐ。
- `T_e` フォワード測度で `R` はマルチンゲールで、ボラティリティは `T_s` まで一定、期間内で `T_e` に向けて線形に 0 まで減る（`g(t) = (T_e - t) / (T_e - T_s)`）。
- Caplet（`τ (R - K)^+` を `T_e` に支払う）は Black または Bachelier の式で、分散の時間を、期間前は `(T_s - t) + (T_e - T_s) / 3`、期間内は `(T_e - t)^3 / (3 (T_e - T_s)^2)` とする。

**検査**（Rust と R のテスト）：

- 解析式と、減衰のある SDE の Euler 法（100 パス × 200 ステップ）が、期間前・期間内、対数正規・正規の 4 通りで標準誤差の 4 倍以内に一致する。100 パスなので緩い検査である（パス数はユーザーの指示）。
- 期間の長さが 0 なら、従来の前決めの Caplet（`compute_caplet_value`）と 1e-12 以内で一致する。期間内の減衰の分だけ、後決めの Caplet は前決めより高い。
- 分散は期間の開始で連続で、期間の終わりで 0 になり、価値は本源的価値に収束する。
- QuantLib v1.42 には FMM がないので、QuantLib との照合はない。

**未対応**：複数の期間の金利の共同経路（段階 4 で LMM と合わせて扱う）、ボラティリティの減衰の他の形、lookback・lockout・観測シフトのある金利。

## 8. 段階 4：LMM の共同経路と校正（2026-11-05）【無裁定の関係と解析式で確認】

実装は `crates/riemann/src/lmm_market.rs`、R は `crates/riemann-r/R/lmm_market.R`（`create_lmm`、`create_exponential_correlation`、`generate_lmm_paths`、`compute_lmm_swaption_value`、`compute_lmm_caplet_value`、`compute_rebonato_swaption_volatility`、`calibrate_lmm_correlation`）。

**計算**：

- 期間フォワード `L_i`（`[T_i, T_{i+1}]`、`T_i` で確定、`T_{i+1}` に支払い）の対数正規モデル。ボラティリティはフォワードごとに一定、ブラウン運動は相関行列で相関させる。
- 共同経路はスポット測度（数値基準 `B(T_{k+1}) = B(T_k)(1 + τ_k L_k(T_k))`、`B(T_0) = 1 / P(0, T_0)`）で、ドリフト `σ_k Σ_{j=η(t)}^{k} τ_j ρ_kj σ_j L_j / (1 + τ_j L_j)` の対数 Euler 法（各ステップの始点のドリフト）。乱数はカウンター方式（種・パス・ステップ × n + フォワード）で、スレッドに依存しない。
- スワップション（`T_a` で行使、`T_b` までのスワップ）は経路上の割引した支払いの平均。Rebonato の近似（重みを今日で固定）で Black のボラティリティも出す。
- 校正：一定のボラティリティなら、フォワード `i` のボラティリティは `T_i` に確定する Caplet の Black のボラティリティそのものなので、Caplet で直接決まる。相関は指数型 `exp(-β |T_i - T_j|)` とし、`β` をスワップションのボラティリティに対する Rebonato の値の最小二乗で黄金分割探索により決める。
- 金利は汎用の期間フォワードで、IBOR の指数・カーブ・fixing は持たない。

**検査**（Rust と R のテスト、2000 パス、各期間 4 ステップ）：

- 無裁定：スポット測度で `E[1 / B(T_k)]` が `P(0, T_k)` に標準誤差の 4 倍以内で一致する（`k` = 1、5、10）。
- 各 Caplet のモンテカルロが Black の式（自分のフォワード測度での解析解）と標準誤差の 4 倍以内で一致する。
- スワップションのモンテカルロと Rebonato の近似の差は、2 万パスで 1.6%（`times` の位置 3 から 7）と 1.3%（位置 5 から 11）、標準誤差の 1.4 倍と 1.1 倍だった。テストでは近似の誤差として値の 2% と標準誤差の 4 倍を許す。
- 校正：`β = 0.3` の Rebonato の値を目標にすると、別の初期値の模型から `β` を 1e-6 以内で回復し、残差は 1e-9 未満。
- QuantLib との照合：9 章。

**未対応**：期間内で変わるボラティリティ、因子数を減らした相関、スワップションのボラティリティ（行列）への個別のボラティリティの校正、終端測度、予測子・修正子法、FMM（段階 3）の金利を含む共同経路、Bermudan スワップションと早期行使。

## 9. LMM の QuantLib との照合（2026-11-05）【ソース確認。照合テストは未実行（アプリ制御）】

**R バインディングで使えるもの**【ソース確認】：旧版の `LiborForwardModel` は QuantLib R パッケージ 1.42 にない。market models の枠組み（`ql/models/marketmodels`）はあるが、具体的なモデル（`FlatVol` など）と経路の生成器（`LogNormalFwdRateEuler` など）のコンストラクターは公開されていない。そのためモンテカルロの経路と価格は比べられない。公開されている次の三つを、決定論的な値で比べる。

- 相関：`ExponentialForwardCorrelation`（長期相関 0、`gamma` 1 で `exp(-β |T_i - T_j|)`。相関は各フォワードの確定時刻の上で定義される）。
- スポット測度のドリフト：`LMMDriftCalculator::computePlain`（数値基準を最初の未確定のフォワードに置く）。共分散の平方根には Cholesky 分解を渡す。R の包み関数は出力の引数を数値のコピーに変えてしまうので、パッケージ自身の C の入口 `R_swig_LMMDriftCalculator_computePlain__SWIG_0` を `DoubleVector` で呼んで値を読む。
- スワップ・レートと割引の比：`LMMCurveState` の `swapRate`、`discountRatio`。

**照合の用意**：`tools/golden/p13_lmm_market.R` が合成入力 6 ケース（フォワード 3〜8 本）で 383 値（相関 93、ドリフト 93、スワップ・レート 58、割引の比 58）を `tests/golden/lmm_market.csv` に書き、`crates/riemann/tests/golden_lmm_market.rs` が Riemann の `create_exponential_correlation`、`compute_lmm_drift`、`compute_lmm_swap_rate` と相対 1e-12 で比べる。

**未実行**：照合テストの実行ファイルを Smart App Control が止めた（os error 4551、CodeIntegrity のイベント ID 3033・3077）。2026-11-05 の 20:43 から 23:25 過ぎまで、間を置いた再試行とビルドのやり直しを含めて一度も実行できていない。回避はしていない。ユーザーの判断で、照合を保留にしてコミットした。実行できたら結果をここに書く。
