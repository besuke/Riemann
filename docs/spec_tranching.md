## 1. 原稿の計算【ソース確認】

原稿のコードは、トランシェ損失 `min(max(l − A, 0), D − A)`（I-11.9、`tranche_loss_LFL()`）と、0〜15% の損失率での 4 トランシェ（0–3%、3–7%、7–10%、10–100%）の表だけである。期待トランシェ損失（I-11.11）と Premium Leg・Loss Leg・フェア・スプレッド（I-11.12）は式だけ、CMO の Sequential・PAC・Support・Z（I-11.4〜11.6）は説明だけで、数値の例はない。

## 2. 実装

`crates/riemann/src/tranche.rs`、R は `crates/riemann-r/R/tranche.R`。

| R の関数 | 内容 |
|---|---|
| `compute_tranche_loss()` | 原稿の式 |
| `compute_tranche_risk(distribution, total, A, D)` | P14 の厳密な損失分布から、期待トランシェ損失、損失を受ける確率 `P(l > A)`、全損の確率 `P(l ≥ D)`、トランシェの VaR。損失率は `(k·unit)/total` で計算し、境界の比較を R と同じ値で行う |
| `compute_lhp_expected_tranche_loss()` | 大数極限（損失 `LGD·p(Z)`）の期待トランシェ損失。`LGD·p(z)` が A・D をまたぐ折れ目 `z = (Φ⁻¹PD − √(1−ρ) Φ⁻¹(K/LGD))/√ρ` で積分区間を分け、各区間を複合 16 点ガウス・ルジャンドル求積 |
| `compute_tranche_legs()` | I-11.12 の式。一定のハザード率 `PD(t) = 1 − exp(−h t)` で各支払日の厳密分布から `E[L_{A,D}(t)]` を求め、Premium Leg（単位スプレッドあたり）`Σ DF(t) Δt E[(D − A) − L_{A,D}(t)]`、Loss Leg `Σ DF(t) ΔE[L_{A,D}(t)]`、フェア・スプレッド |
| `compute_sequential_cmo()` | Sequential（I-11.4）。最後を Z にすると、前のトランシェが残る間は利息を元本に加え、その現金を前のトランシェの元本の返済に回す（I-11.6） |
| `compute_pac_schedule()`、`compute_pac_support_cmo()` | PAC の予定元本は、二つの PSA でのプールの元本の小さい方（月ごと）。PAC に予定分と過去の不足分を先に払い、残りを Support、Support の償還後は PAC に払う（I-11.5） |

担保は P11-5 のパススルー MBS（`compute_mbs_cashflows()`）。利息は月初の残高にクーポン/12。トランシェに払った後の担保の現金は残余（residual）として返す。

## 3. 照合の結果【実行照合済み】

照合日 2026-11-15。R 4.6.0、RiemannFinMath 0.3.0（参照値では担保のキャッシュフローだけに使う）。参照値の損失分布は z 方向の台形公式（刻み 0.002）、ウォーターフォールは R の素朴なループで、Rust とは独立に書いた。

| 比べたもの | 実際の最大差 | 採用した許容誤差 |
|---|---|---|
| 原稿の例のトランシェ損失（151 点 × 4） | 1e-16 未満 | 1e-16 |
| 期待トランシェ損失（ρ = 0.1, 0.2, 0.4 × 4 トランシェ） | 6.1e-17 | 1e-15 |
| 損失を受ける確率・全損の確率 | 3.7e-15 | 1e-13 |
| トランシェの VaR 99% | 一致 | 1e-17 |
| 大数極限の期待トランシェ損失 | 相対 5.3e-15 | 相対 1e-11 |
| 各支払日の期待トランシェ損失（20 日 × 4） | 1.2e-16 | 1e-14 |
| フェア・スプレッド | 相対 6.1e-15 | 相対 1e-11 |
| CMO（Sequential＋Z を 100%・300% PSA、PAC/Support を 50%・150%・400% PSA）：元本・利息・加算利息・残余・WAL・PAC の予定元本 | 7.1e-15 | 1e-12（予定元本は 1e-15） |

**大数極限の精度について**：折れ目で区間を分ける前は、Rust（区間を分けない 2000 区間）と R の `integrate()`（区間を分けない）の相対差が 4.5e-9 だった。折れ目は両方の求積の精度を落とす。ユーザーの判断（2026-11-15）では 4.5e-9 でも今回の照合には十分だが、折れ目で分ける変更はすでに入れてあり、Rust・R とも分けたうえでの差は 5.3e-15 になった。R の `integrate()` は `rel.tol` が 1.1e-14（50ε）未満を受け付けず、1.2e-14 では丸め誤差の検出で止まるので、`rel.tol = 1e-12`、区間は [−12, 12] とした。テストの許容誤差 1e-11 は、この R 側の指定に合わせたもので、精度調整はここで打ち切った。

### 3.1 損失配分の検算

| 検算 | 結果 |
|---|---|
| 損失の格子点ごとに、4 トランシェの損失の合計 = その損失率（101 点 × ρ 3 通り） | 最大差 5.6e-17 |
| 4 トランシェの期待損失の合計 = ポートフォリオの期待損失率 165/10000 = 0.0165 | 差 3.5e-18〜1.4e-17 |
| 全損の確率 − 次のトランシェが損失を受ける確率 = 境界の格子点の確率 `P(l = D)` | 差 1e-15 未満。境界（3%・7%・10%）は 0.6% の格子に乗る（3% は 5 社、7% には乗らない）ので、`P(l ≥ D)` と `P(l > D)` の違いがその確率になる |
| 4 トランシェの Loss Leg の合計 = 0〜100% の Loss Leg | 0.07519799206461908 と …912（差 4e-17） |
| CMO：月ごとに、各トランシェの利息と元本の合計＋残余 = 担保の利息と元本 | R のテストで 1e-12 以内 |

主な値（ρ = 0.2、5 年、四半期、割引 1%）：期待トランシェ損失は Equity 1.23%、Mezzanine 0.33%、Junior 0.059%、Senior 0.031%（ポートフォリオに対する割合）。フェア・スプレッドは年率で Equity 51.1%、Mezzanine 17.3%、Junior 8.4%、Senior 0.34%。PAC（700）の WAL は 50% PSA で 8.77 年、150% で 6.10 年、400% で 4.41 年、Support（300）は 15.07 年、7.25 年、2.00 年。100%〜300% PSA の帯の中では PAC の WAL が変わらないことを R のテストで確かめた。
