## 2. 実装

`crates/rmql/src/credit_risk.rs`、R は `crates/rmql-r/R/credit_risk.R`。

| R の関数 | 内容 |
|---|---|
| `compute_conditional_pd()` | 条件付き PD |
| `compute_credit_loss_distribution(pd, ead, lgd, rho, unit, panels)` | **損失分布そのもの**。各社の損失 `EAD·LGD` が `unit` の整数倍のとき、`Z = z` を固定すれば独立なので、損失の格子上の分布を債務者ごとの漸化式で求め、`z` について複合 16 点ガウス・ルジャンドル求積（[−10, 10]、既定 200 区間）で積分する |
| `compute_credit_risk(distribution, confidence_level)` | 分布から EL、VaR（`P(L ≤ l) ≥ α` の最小の l）、UL、ES（Rockafellar–Uryasev）、`E[L | L ≥ VaR]`（原稿の定義） |
| `simulate_credit_losses()` | モンテカルロの損失（カウンター方式の乱数、`Z` は次元 0、`ε_i` は次元 i+1。スレッド数によらない）。集計は P13 の `compute_loss_risk()` |
| `compute_asrf_var()` | ASRF の分位点 `Σ EAD LGD Φ((Φ⁻¹PD + √ρ Φ⁻¹α)/√(1−ρ))` |
| `compute_irb_capital(pd, lgd, maturity, ead)` | バーゼル IRB（事業法人、CRE31）の相関 R(PD)、満期調整 b(PD)、所要自己資本 K、RWA = 12.5 K EAD。PD フロアは掛けない |

**求積の選択【実行照合済み】**：最初はガウス・エルミート求積（Golub–Welsch）で実装したが、ρ = 0.4 で 400 ノードでも R との差 2.1e-12、計算に 4.4 秒かかった。100 社あると、ある損失額の条件付き確率が `z` の狭い範囲だけに山を持つためである。短い区間に分けた複合ガウス・ルジャンドル求積に替え、50 区間で差 3e-15 以内、200 区間で 0.05 秒になった。

## 3. 照合の結果【実行照合済み】

照合日 2026-11-15。R 4.6.0、furrr 0.4.0、future 1.75.0。R の参照値の損失分布は、`z` 方向の台形公式（刻み 0.001、[−12, 12]）で求めた（Rust の求積とは別の方法）。

| 比べたもの | 判定 |
|---|---|
| 損失分布の各確率（ρ = 0, 0.1, 0.2, 0.4、各 101 点）：R の台形公式との差 | 最大 3.4e-15（許容 1e-13） |
| 平均・標準偏差、VaR（95・99・99.9%）、ES 二つ | VaR は一致、ES は 1e-7 以内 |
| ASRF の分位点（99・99.9%） | 相対 1e-13 以内 |
| IRB（PD 0.03%〜20% の 8 点、M = 2.5 と 5）：相関・満期調整・K | 相関と満期調整は 1e-15、K は相対 1e-12 以内 |
| 条件付き PD（z = −4〜4） | 相対 1e-11 以内。z = 4 では引数が −4.3 になり、QuantLib 互換の正規分布関数と R の `pnorm` が相対 2.8e-12 違う（この関数は QuantLib との一致のために変えない） |

ρ = 0.20 の主な値（厳密な分布）：EL 165、標準偏差 218、VaR 95% 600・99% 1020・99.9% 1680、ES（Rockafellar–Uryasev）857・1304・1974、`E[L | L ≥ VaR]` 836・1277・1943。

| モンテカルロ（ρ = 0.20） | 厳密 | rmql（10 万本） | 原稿（furrr、10 万本） |
|---|---|---|---|
| VaR 95% / 99% / 99.9% | 600 / 1020 / 1680 | 600 / 1020 / 1680 | 600 / 1020 / 1680 |
| `E[L | L ≥ VaR]` 99% | 1276.6 | 1275.7 | 1271.1 |
| 同 99.9% | 1943.1 | 1938.5 | 1935.6 |

損失が 60 刻みの格子に乗るので、十分な本数では標本の VaR が厳密な VaR と同じ格子点になる。原稿の感度分析（2 万本ずつ）は、ρ = 0.4 の 99.9%（その上に 20 本しかない）で type 7 の補間が 3060.06 となり、厳密値 3000 と格子 1 目盛り強ずれた。テストでは 99% で 1 目盛り、99.9% で 2 目盛りまでを許す。

**ES の定義の差**：原稿の `loss >= VaR` の平均は、VaR の格子点の確率質量をすべてテールに入れるので、Rockafellar–Uryasev の ES より小さい（99% で 1277 と 1304）。原稿 I-10.11 の注記のとおりで、両方を返す。

## 4. DRC との関係【設計案・基準本文は未確認】

FRTB のデフォルト・リスク・チャージ（DRC）は、トレーディング勘定の発行体のデフォルトによる損失を、市場リスクの ES とは別に資本賦課する枠組みである。内部モデル方式では、1 年・99.9% のデフォルト損失の VaR を、システマティック・ファクターを持つデフォルト・シミュレーションで求める。これは本章の One-Factor Gaussian の損失分布の 99.9% 分位点（`compute_credit_risk(d, 0.999)`、`simulate_credit_losses()`）と同じ構造で、IRB の資本（`compute_irb_capital()`）も同じ ASRF の考え方に立つ。

ただし、次の点は今回 Basel の基準本文（MAR22・MAR33）を確認しておらず、実装もしていない。

- 内部モデル方式の DRC が求めるファクターの数と構成（複数のシステマティック・ファクター）、相関の推定期間、ポジション一定の仮定、価格変動を伴うデフォルト時損失（JTD）の扱い
- 標準的方式の DRC（JTD、格付ごとのリスクウェイト、ヘッジ・ベネフィット比率、バケット）

実装するときは、基準本文を読んで条文番号を記録し、本文の例で照合する。
