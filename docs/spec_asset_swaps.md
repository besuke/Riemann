# アセットスワップと国債先物のベーシスの仕様（P7）

実装は `crates/riemann/src/asset_swap.rs`、R の入口は `crates/riemann-r/R/asset_swaps.R` である。定義は GaussQuant の `ois_asset_swap_GQL`、`ois_asset_swap_jpy_from_legs_GQL` と LagrangeFinance II-2.6、II-3.7 に従う。

## 1. OIS アセットスワップ

パー・パー型である。債券を支払い、翌日物の複利レグにスプレッドを足して受け取る。ダーティー価格とパーの差は開始時に交換する。カーブは予測と割引の両方に使う。

| 項目 | 定義 |
|---|---|
| 開始日 | 債券の受渡日 |
| 満期 | スケジュールの最後の日 |
| 翌日物レグの支払い | `名目 × (P(開始) / P(終了) - 1)`。日付は QuantLib `MakeOIS` に従う（[spec_ois.md](spec_ois.md)） |
| スプレッドのアニュイティ | `Σ 名目 × 年数 × P(支払日)`。年数は指標の日数計算による |
| 公正スプレッド | 価値を 0 にするスプレッド |
| 公正なクリーン価格 | 契約のスプレッドで価値が 0 になるクリーン価格 |

対象は、額面 100 で償還する満期一括の債券だけである。

**気配についての感応度**（`asset_swap_quote_sensitivity`）：公正スプレッドをカーブのノードについて自動微分し、解いたカーブでの陰関数定理で気配についての微分に変換する。スプレッドが変わる仕組みを 1 回の計算で読める。

## 2. 円ベーシス込みアセットスワップ

外貨建て債券を、円担保で名目一定の通貨スワップにより円に変換する。

`F(t) = S × [Pf(t)/Pf(t0)] / [Pj(t)/Pj(t0)] × exp(-z (t - t0))`

定数 `z` は、指定のベーシスで満期の通貨スワップがパーになるように Brent 法で解く。**簡略化したモデル**である。担保の選択、ベーシスの期間構造、名目のリセット、信用・調達・取引コストの調整はない。

## 3. 国債先物のベーシス

`Gross Basis = P - F × CF`、`Carry = クーポン収入 + (AI_T - AI_0) - 調達コスト`、`Net Basis = Gross Basis - Carry` である。インプライド・レポは `(F × CF + AI_T + クーポン収入 - ダーティー価格) / ダーティー価格 / 年数` とする。年数は日数 / 365 である。

コンバージョン・ファクターは取引所が定める値であり、入力とする。計算はしない。受渡適格銘柄のうち、同じ入力で Net Basis が最小の銘柄を CTD とする（`future_basket`）。受渡の選択権の価値は含まない。

## 4. 照合結果【実行照合済み】（2026-11-01）

入力はすべて合成である（`tools/golden/p7_asset_swaps.R`）。カーブは GaussQuant の節点をそのまま Riemann に渡すので、下の比較にブートストラップの差は含まれない。

| 対象 | 比べた相手 | 件数 | 最大の差（絶対） |
|---|---|---|---|
| OIS アセットスワップ（4 通貨、公正スプレッドと各レグ） | GaussQuant `ois_asset_swap_GQL` | 80 | 6.8e-13 |
| 円ベーシス込み（3 通貨） | GaussQuant `ois_asset_swap_jpy_basis_GQL` | 45 | 2.1e-9（`z` を解く手順が違うため。bp の単位） |
| 先物のベーシス | QuantLib の経過利子と同じ式 | 60 | 0 |
| 気配の感応度 | カーブを作り直した中心差分 | 7 気配 | 1e-5 以内（Rust のテスト） |

カーブも各自で作る比較は検証 QMD にある（基準は差 1e-6 bp）。

GaussQuant の `ois_asset_swap_GQL` は、P3 で未実施としていた GaussQuant との比較の一部になる。

市場価格との照合はしていない。
