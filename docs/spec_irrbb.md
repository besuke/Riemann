# IRRBB の金利ショック・シナリオ（SRP31.90〜31.93）

QuantLet の「IRRBB金利シナリオ」のために追加した（2026-11-15）。中核は `crates/rmql/src/irrbb.rs`、R の入口は `R/irrbb.R`。QuantLib のソースは使っていない。

## 1. 参照した基準【ソース確認】

バーゼル枠組み SRP31「Interest rate risk in the banking book」。現行版は 2024-07-16 公表、2026-01-01 適用（bis.org の SRP31 の改訂履歴で確認。旧版は 2019-12-15 適用）。

| 段落 | 内容 |
|---|---|
| SRP31.90 | 6 シナリオ（上方・下方パラレル、スティープ化、フラット化、短期金利上昇・低下）。通貨別のショック幅（Table 2）。円はパラレル 100・短期 100・長期 100 bp |
| SRP31.91 | 形状。パラレルは全年限で一定、短期は `S·exp(−t/x)`（x = 4）、長期は `L·(1−exp(−t/x))`、スティープ化とフラット化は短期・長期の組み合わせ |
| SRP31.92 | 計算例（円、3.5 年）：短期の係数 0.417、スティープ化 `−0.65 × 100 × 0.417 + 0.9 × 100 × (1−0.417) = +25.4 bp`、フラット化 `+0.8 × 100 × 0.417 − 0.6 × 100 × (1−0.417) = −1.6 bp` |
| SRP31.93 | ショック後の金利のフロアは各国当局の裁量で設けてよい（0 以下） |

SRP31.91 の式は bis.org では画像で、文字としては読めなかった。スティープ化（−0.65、+0.9）とフラット化（+0.8、−0.6）の係数は、SRP31.92 の計算例の文字から確かめた。Table 2 の値は、文字として読めた通貨（JPY、USD、EUR、GBP、CHF、CAD、CNY、ZAR）だけを `get_irrbb_shock_sizes()` に入れた。ほかの通貨はショック幅を引数で与える。

## 2. 実装【設計】

- `compute_irrbb_shock(t, scenario, sizes, x)`：年限 `t`（年）のショック
- `compute_irrbb_curve_points()`：基準カーブのゼロ金利（Actual/365 Fixed、連続複利）を日付ごとに取り、ショックを加え、フロアを当てた点
- `create_irrbb_shocked_curve()`：その点のゼロ金利カーブ（ゼロ金利を線形補間）。`scenario = "base"` は同じ日付で基準カーブを作り直す（評価の差がショックだけから生じるように）
- フロア：`NULL` ならなし。値を与えると 0 以下に限り、`max(基準＋ショック, min(基準, フロア))`（基準がフロアより低い年限は、フロアで金利を上げない）

## 3. 照合【実行照合済み】

2026-11-15。`trs.rs` と同じく、単体テスト 3 件（`irrbb::tests`）と `tests/testthat/test-irrbb.R`（20 項目）。全テスト 277 件合格（`cargo test --release -j 1`。並列のリンクでは LNK1104 が出た。後述）、`cargo clippy --all-targets -- -D warnings` 警告なし。

| 照合 | 結果 |
|---|---|
| 円のパラレル（0〜30 年の 10 点） | 全年限で ±100 bp |
| 円のスティープ化・フラット化・短期金利上昇（3.5 年） | 25.4・−1.6・41.7 bp（SRP31.92 の計算例と一致。式の値 25.386… bp） |
| 6 形状の式（R で直接計算） | 差 1e-13 以内 |
| ショック後カーブの点 = 基準ゼロ金利＋ショック | 差 1e-12 以内。0% のフロアで基準より下げないこと、0 を超えるフロアを拒むことも確認 |
| ショック後カーブ上の債券価格 = キャッシュフローを補間したゼロ金利で割り引いた和（R で直接計算） | 相対差 1e-12 以内。上方パラレルで価格が下がり、下方で上がる |

**全テストのリンク**：並列ビルド（既定）では、今回の変更と関係のないテストの実行ファイルで LNK1104 が 3 回続いた。実行ファイルを使っているプロセスはなく、同じ時刻のイベントログにはセキュリティソフトの記録があった（原因は未確認）。`-j 1` では全 30 個がリンクでき、すべて合格した。
